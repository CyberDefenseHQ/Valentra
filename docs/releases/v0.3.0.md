# Valentra v0.3.0

## Sprint 0 Release 3 — Identity Foundation

Release 3 expands the Valentra application foundation with initial identity, authentication, and audit logging components.

### Added

- User model with username, password hash, and role fields
- Authentication blueprint and `/login` route scaffolding
- Audit logging service foundation

### Maintained

- Flask application factory
- Dashboard route
- `/health` health-check endpoint
- SQLAlchemy database integration
- Flask-Login integration
- Bcrypt integration
- Flask-Migrate integration

### Current Limitations

Authentication and authorization are not yet fully implemented. The `/login` endpoint is currently a placeholder, and the identity components provide the foundation for future security functionality.
