# Valentra v0.4.0

## Sprint 0 Release 4 - Professional UI Shell

Release 4 introduces the professional user interface foundation for Valentra while preserving the application and identity foundations established in previous releases.

### Added

- Shared application base template
- Security platform navigation
- Security overview dashboard
- Security Score summary card
- Active Incidents summary card
- Detection Rules summary card
- CSS styling foundation
- JavaScript application foundation

### Maintained

- Flask application factory
- `/health` health-check endpoint
- `/login` authentication route scaffolding
- User model and role field
- Flask-Login integration and user loader
- SQLAlchemy database integration
- Bcrypt integration
- Flask-Migrate integration
- Audit logging foundation

### Current Limitations

Dashboard metrics are currently demonstration values and are not generated from live security-event data.

Detection, Identity, Incidents, and Reports are represented in the navigation but do not yet provide complete application workflows.

Authentication and authorization remain under development.

## Sprint 0 Status

Release 4 completes Sprint 0. The project now has the application, identity, and user interface foundations required to begin implementing functional security-event ingestion and detection workflows in Sprint 1.
