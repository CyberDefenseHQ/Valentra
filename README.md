# Valentra

![Valentra Logo](docs/images/valentra-logo.png)

**Version 0.3.0 — Sprint 0 Release 3**

Valentra is a security engineering portfolio project designed to demonstrate the development of a modular security platform.

## Release 3

Sprint 0 Release 3 introduces the identity foundation while preserving the application foundation established in Release 2.

### Current Components

- Flask application factory
- SQLAlchemy database integration
- Flask-Login foundation
- Bcrypt integration
- Database migration support
- Dashboard route
- Health-check endpoint
- User model with role field
- Authentication route scaffolding
- Audit logging foundation

## Current Status

Valentra is under active development. Authentication, authorization, security-event processing, detection logic, and incident workflows will be implemented incrementally in future releases.
